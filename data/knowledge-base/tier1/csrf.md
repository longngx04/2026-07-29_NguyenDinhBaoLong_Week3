# CSRF — Cross-Site Request Forgery

Trang độc hại khiến trình duyệt đã đăng nhập gửi request state-changing tới app nạn nhân.

Mitigation: anti-CSRF token, SameSite cookie, xác nhận lại hành động nhạy cảm.
